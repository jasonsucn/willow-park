# 晴湾公园 · Willow Park

一处可以自由环视、听自然声、看湖水波光的交互式 3D 公园。全部景物为程序化几何建模，无外部图片、模型或音频请求。

## 最简单的使用方法

双击同目录的 `晴湾公园.html`，使用支持 WebGL 2 的新版 Edge 或 Chrome 打开。该文件约 0.8 MB，已嵌入 Three.js、样式、场景、角色和音乐代码，可离线使用，不需要安装软件或启动服务器。

浏览器安全策略不允许网页未经操作自动播放声音。进入后点击「听见自然的声音」的播放按钮，或者底部的声音按钮即可开启。

## 内容与交互

- **水面**：平面实时倒影、菲涅耳反射、多频动态细波、阳光高光、浅岸变化、睡莲、小鸭和扩散涟漪。点击湖面会出现新的涟漪，并在开启声音后播放轻柔水滴音。
- **景观**：环湖石板路、曲桥、六角湖心亭、逐片屋瓦、垂柳、树林、樱花、六处花坛、细草、长椅、路灯、指路牌、野餐毯、书与果篮。
- **生命**：8 位有不同装束的散步者、3 只狗，主角为柯基「饼干」；包括步行、摆臂、跑步、摇尾、停顿嗅闻，以及牵犬人。湖上小鸭、空中鸟群、花边蝴蝶与阳光浮尘持续活动。
- **视角**：湖畔全景、湖心小亭、小狗跟随。点击顶部「发现美好」还可以进入四季花园。
- **时光**：拖动时光滑杆，从清晨到日落，改变天空、阳光、湖水和灯光氛围。
- **声景**：Web Audio 实时合成的轻柔五声音阶钢琴、和声垫、低音、流水、风声与鸟鸣；支持「自然与音乐 / 纯净自然 / 轻柔音乐」及音量调整。

### 操作

| 输入 | 功能 |
|---|---|
| 鼠标拖动 / 单指拖动 | 环视公园 |
| 滚轮 / 双指缩放 | 拉近、拉远 |
| 点击湖水 | 生成涟漪 |
| 点击长椅 | 轻柔的短句反馈 |
| 方向键 | 调整视角（焦点不在输入控件上时） |
| `+` / `-` | 缩放 |
| 右上角全屏按钮 | 全屏欣赏 |

## 运行源码版本

已有 Node.js 时，在本目录运行：

```powershell
node preview.cjs
```

打开 `http://127.0.0.1:8088`。预览服务仅监听本机。`index.html` 加载本目录内的其他源码，无 CDN 依赖。

修改源码后运行：

```powershell
python build.py
```

重新生成独立的 `晴湾公园.html`。

## 技术与性能说明

- 使用本地 Three.js r160，遵循 MIT 许可；许可证头保留在渲染库和单文件产物内。
- 静态物体合批、花草树叶实例化、人物及动物的关节矩阵实例化；反射纹理与阴影按需刷新。
- 检测到 SwiftShader / 软件渲染时自动降低叶片细分、细草与花朵数量、像素密度和反射精度。正常显卡使用更精细的配置。
- 最佳观感建议使用桌面浏览器并开启硬件加速。纯软件渲染仍可运行，但帧率会明显受限；本次浏览器测试环境即为 SwiftShader，不能代表独立显卡的流畅度。
- 这是精细的程序化、自然风格场景，而非扫描资产或摄影测量级写实场景；水体为实时着色器视觉模拟，不是流体物理求解。

## 文件

- `晴湾公园.html`：直接交付使用的单文件。
- `index.html` / `style.css` / `scene.js` / `life.js` / `audio.js` / `app.js`：可维护的拆分源码。
- `build.py`：零额外依赖的单文件打包脚本。
- `qa.html`：浏览器检查页，用于检查运行状态、声景、视角、移动尺寸和着色器错误。
